# Social App

A modern social media web application that allows users to create accounts, share posts, interact with others, and explore content in a clean and responsive interface.

Built using modern web technologies to provide a smooth user experience and scalable architecture.

---

## 🚀 Features

- User authentication (Login / Register)
- Create and share posts
- Like and interact with posts
- Responsive UI for mobile and desktop
- Modern component-based architecture
- Clean and maintainable code structure

---

## 🛠 Tech Stack

Frontend:
- React.js
- Next.js
- TypeScript
- Tailwind CSS

Backend / Data:
- API Integration
- RESTful services

Tools:
- Git
- GitHub
- Vercel (for deployment)
